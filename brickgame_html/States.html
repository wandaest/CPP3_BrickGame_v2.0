1.1 States ¶

  • START (0): Initial state, waiting for game start.
  • SPAWN (1): Preparing initial snake and apple positions.
  • MOVING (2): Active snake movement.
  • PAUSE (3): Game paused.
  • GAMEOVER (6): Game over due to collision.
  • WIN (8): Game won when snake length reaches 200.
  • EXIT_STATE (7): Exit game.

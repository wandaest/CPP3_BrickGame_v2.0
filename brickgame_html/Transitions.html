1.2 Transitions ¶

  • START -> SPAWN: On Start action.
  • SPAWN -> MOVING: On NOSIG action.
  • MOVING -> PAUSE: On Pause action.
  • PAUSE -> MOVING: On Pause action.
  • MOVING -> GAMEOVER: On collision.
  • MOVING -> WIN: When length = 200.
  • Any state -> EXIT_STATE: On Terminate action.
